## 这是什么

如果你桌面上堆了上百个图标，想整理又不敢动手——怕文件找不到、怕移完就乱回不来——那这个工具就是为这个场景写的。

它做四件事：

| 功能 | 说明 | 能不能反悔 |
|---|---|---|
| **文件整理** | 按六类（办公文档 / 图片 / 记事本 / 文件夹 / 压缩包 / 未知）把桌面文件移到你指定的文件夹 | ✅ 一键撤销，文件按原路回桌面 |
| **快捷方式重排** | 把桌面 `.lnk` 按 工具 / 小众软件 / 游戏 / 文件 分堆，左右对称对齐（实验性） | ✅ 用备份或整理记录还原 |
| **清理失效快捷方式** | 找出目标已经不存在、点了没反应的死图标，收进隔离区 | ✅ 隔离区保留原文件，可放回 |
| **软件卸载** | 读注册表列出全部可卸载软件，带图标和占用量 | ⚠️ 卸载是不可逆的，会二次确认 |

外加一个**桌面备份**：动手前先把桌面状态存一份快照，任何时候能整体回滚。

## 为什么它是安全的

这类工具最大的风险是「删了不该删的」。所以设计上有几条硬约束：

- **先给方案，再动手**。点「开始整理」会先弹出完整的移动清单（哪个文件去哪个文件夹），你确认了才真的移动。
- **移动不是删除**。所有操作都是 `fs.rename`，文件从桌面挪到你的文件夹里，不是丢进回收站。
- **撤销是原路返回**。每次整理都留一份 `manifest`，记录每个文件的原始路径，撤销时逐个还原。
- **清理进隔离区，不进黑洞**。失效快捷方式被移到 `data/cleanup/<批次ID>/`，隔离区里躺着原文件，随时能「放回桌面」。
- **不联网，不上传**。整个程序只监听 `127.0.0.1:4390`，没有任何外部请求。你的文件名、软件列表不会离开这台电脑。

## 它是怎么「认出」你的桌面的

不是写死的，是运行时读的：

- 桌面路径 → `SHGetKnownFolderPath`（支持被重定向到 D 盘的桌面）
- 快捷方式目标 → 解析 `.lnk` 二进制结构，读出真实 exe 路径
- 软件列表 → 注册表三处 `Uninstall` 项（HKLM / WOW6432Node / HKCU）
- 图标 → `SHCreateItemFromParsingName` + `IShellItemImageFactory` 提取 256px 原图
- 分辨率 / DPI → `SetThreadDpiAwarenessContext` + 实际网格测量

换一台电脑、换一个用户名、把桌面搬到别的盘，都不用改代码。

## 下载使用（推荐）

到 [Releases](../../releases) 下载 **`桌面整理器-便携版.zip`**（约 32 MB）：

1. 解压到任意文件夹（建议不要放在 C 盘根目录，也别放在桌面上）
2. **右键 zip → 属性 → 勾选「解除锁定」→ 确定**（重要，见下方说明）
3. 双击 `桌面整理器.exe`
4. 浏览器会自动打开界面；没有的话手动访问 `http://127.0.0.1:4390`

便携版自带 Node 运行时，**不需要安装 Node，不需要安装任何东西**，也不需要管理员权限。

> 解压后有个 `第一次使用请读我.txt`，遇到提示先看它。

### 关于「Windows 已保护你的电脑」

双击 exe 可能看到蓝色提示框「Windows 已保护你的电脑」。

原因很直接：**这个 exe 没有数字签名**。代码签名证书一年几千块，个人项目买不起；而且从 2024 年起，连 EV 证书也不再默认通过 SmartScreen 信誉。这不是杀毒软件判断它有毒，只是 Windows 不认识发布者。

处理方式：点「更多信息」→「仍要运行」。

另外还有两类提示可能会遇到：

| 提示 | 为什么 | 怎么办 |
|---|---|---|
| 「无法验证发布者」 | 同上下，没签名 | 更多信息 → 仍要运行 |
| 杀软报「行为可疑」 | 程序要读注册表软件列表、调 Shell 接口取图标、调 PowerShell 读快捷方式——这些行为和某些恶意软件重合 | 加信任 / 白名单。源码全在这里，可以自己看 |

**如果你不放心，建议直接用源码跑**（见下一节），一共 1 万多行 JS，没有一行是加密的。

## 从源码运行

需要 Node.js 18+（[官网下载](https://nodejs.org/)）。

```bash
git clone <本仓库地址>
cd DesktopOrganizer
node server.js
```

然后浏览器打开 `http://127.0.0.1:4390`。就这样，没有 `npm install`——因为**这个项目零第三方依赖**，只用了 Node 内置模块。

## 自己打包便携版

```bash
node tools/make-launcher.js   # 编译 exe 启动器（需要 .NET Framework 4.6.2+，Win10/11 自带）
node tools/pack.js --portable # 生成 dist/桌面整理器-便携版.zip
```

`tools/pack.js` 会把当前 Node 运行时一起复制进去，所以打出来的包在没装 Node 的电脑上也能跑。

## 技术栈

**Node.js 内置模块 + 原生 HTML/CSS/JS。没有框架，没有构建步骤，没有 node_modules。**

```
server.js         HTTP 服务 + 全部 API 路由
organizer.js      文件整理 / 撤销
classify.js       文件分类规则（扩展名 + 关键词 + 路径特征）
desktopicons.js   桌面图标网格读取与重排
shortcuts.js      .lnk 解析
cleanup.js        失效快捷方式检测与隔离
uninstall.js      软件列表与卸载
backup.js         桌面快照
icons.js          256px 图标提取
winutil.js        PowerShell / 系统路径兼容层
public/           前端（index.html + app.js + style.css）
tools/            图标生成、exe 编译、打包脚本
```

## 已知限制

- **只支持 Windows 10 / 11**。依赖 Win32 API 和 PowerShell，Linux / macOS 跑不了。
- **快捷方式重排是实验性的**。不同 Windows 版本的桌面网格行为有差异，个别情况下图标位置会和预期差一格。
- **UWP / Microsoft Store 应用不在卸载列表里**。它们走的是另一套卸载接口，目前没做。
- **移动软件安装位置后会留下孤儿注册表项**。程序不会自动删除它们（删注册表风险太高），只在你手动卸载后可能看到残留项。
- 便携版**换文件夹位置后**，桌面快捷方式会失效，需要重新运行一次 `放到桌面（可选）.vbs`。
