桌面整理器 · 便携版 · 第一次使用请读我
========================================

这一版把运行环境一起打包了（node\ 文件夹里那个 node.exe，84 MB），
所以：解压 → 双击 → 就能用，不用装 Node，也不用装任何东西。


【开始用：解压，双击 exe，就完事了】
  1) 把整个压缩包解压到一个你有写权限的文件夹，例如：
         D:\桌面整理器\
     别解压到 C:\Program Files 里面（那里写文件需要管理员权限，
     程序要往自己的 data\ 里存配置和记录，会失败）。

  2) 双击文件夹里的「桌面整理器.exe」，窗口直接打开，到此结束。
     它是一个正常的 Windows 程序（带自己的图标），没有安装过程：
     不写注册表、不装服务、不设开机自启、不往系统目录放东西。

     （万一 exe 打不开，双击同目录的「桌面整理器.vbs」效果完全一样，
       那是启动脚本；实在不行还有「桌面整理器.bat」。）

  3) 关掉窗口等于退出；后台进程空闲 60 分钟也会自己结束。

  【可选的第二步】想从桌面图标启动的话，双击「放到桌面（可选）.vbs」一次，
     桌面会出现蓝色的「桌面整理器」图标，以后双击它就行。
     不放桌面完全不影响使用，直接双击文件夹里的「桌面整理器.exe」也一样。


【它做什么】
  · 整理桌面：把桌面上的文件按类型收进指定文件夹，移动前先给你看方案，事后能一键撤销。
  · 备份桌面：整个桌面原样复制一份，随时还原。
  · 清理桌面：把不想要的快捷方式收走（进回收站，不是永久删除），随时「放回桌面」。
  · 快捷方式重排：按分类把桌面图标排成整齐的几块，取消/预览都行。
  · 卸载软件：勾选多个软件，自动逐个弹出卸载向导；也能列出所有已安装的软件。


【安全承诺】
  · 任何删除都进回收站，软件里还留一份原始记录，随时能还原。
  · 移动文件前一定先给方案，你点「开始整理」才真的动。
  · 不删注册表、不碰系统目录、不改系统设置。
  · 不需要管理员权限。只有个别卸载程序自己要提权时，才会弹「用户账户控制」。


【系统要求】
  · Windows 10 1607 及以上 / Windows 11（21H2 ~ 25H2），64 位
  · 不需要装 Node.js（已经带在 node\ 里了，版本 22）
  · PowerShell 5.1、.NET Framework 4.x（系统自带，不用另外装）
  · 不支持：Windows 7 / 8、Windows 11 S 模式、32 位系统


【文件说明】
  桌面整理器.exe          ← 双击这个就能用，唯一入口（带自己的图标）
  桌面整理器.vbs          ← 备用入口，exe 打不开时用它，效果一样
  桌面整理器.bat          再备用（会留一个最小化的黑窗口）
  放到桌面（可选）.vbs     只做一件事：在桌面放个快捷方式，不用也行
  node\node.exe          运行环境，84 MB，package 大就是因为这个。
                         它只用来跑本程序，不会装服务、不会开机自启。
  server.js 等 .js 文件  程序本体（由 exe 调用，不用管它们）。
  public\                界面文件。
  app.ico                图标。
  data\                  你的配置和记录，第一次运行才生成。
  使用说明.txt           完整功能说明和排错。


【会遇到的提示，都不是问题】

  1) 「Windows 已保护你的电脑」（SmartScreen 全屏蓝框）
     因为这是没有购买数字签名的程序，Windows 不认识它。点
        「更多信息」→「仍要运行」
     即可，一台机器只需点这一次。

     想完全避免它：解压之前，右键点击下载的 zip → 属性 →
     勾选「解除锁定」→ 确定 → 再解压。这样解压出来的文件就没有
     「从网上下载」的标记，双击不会再被拦。
     （用微信 / QQ 传来的 zip 更容易带这个标记，同样处理。）

  2) 「打开文件 - 安全警告：无法验证发布者」
     只有在你选择用 .vbs / .bat 启动时才会出现，点「运行」即可。
     用 桌面整理器.exe 启动不会看到这个。

  3) 杀毒软件报 node.exe 可疑
     node.exe 是 Node.js 官方运行时，原样打包没改过；node\LICENSE.txt
     是它的授权文件。介意的话改用「标准版」（需要自己装 Node）。

  4) Windows 提示「是否允许此应用通过防火墙」
     不用允许，它只监听 127.0.0.1（本机），不对外联网。


【移动位置会失效的地方】
  桌面快捷方式里存的是绝对路径。把文件夹挪到别处以后，
  双击桌面图标会打不开 —— 重新双击一次「放到桌面（可选）.vbs」就好
  （或者干脆直接双击文件夹里的「桌面整理器.exe」）。


【数据放在哪】
  都在本文件夹的 data\ 里（配置、整理记录、清理记录、图标缓存）。
  整个文件夹可以直接拷到 U 盘、另一台电脑，双击就能用。
  不想要历史记录，删掉 data\ 就行，下次启动会自动重建。


【卸载这个工具】
  删掉这个文件夹，再删掉桌面上的「桌面整理器」快捷方式。
  它没往注册表、没往系统目录写过任何东西。
