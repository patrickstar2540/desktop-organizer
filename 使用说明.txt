桌面整理器 · 使用说明
========================================

【怎么打开】
  没有安装过程，解压就能用：双击文件夹里的「桌面整理器.exe」，窗口直接打开。
  它是一个正常的 Windows 程序（带自己的图标），本身只有 370 KB，作用是找到 Node
  并把 server.js 跑起来；不写注册表、不装服务、不设开机自启；关掉窗口等于退出。

  想从桌面图标启动（可选）：双击「放到桌面（可选）.vbs」一次，
  桌面会出现「桌面整理器」图标，以后双击它就能打开。
  如果不放桌面，每次双击「桌面整理器.exe」效果完全一样。

  三个入口按顺序都试过就能启动，效果一样，只是提示不一样：
    桌面整理器.exe  首选（无控制台窗口，不弹脚本安全警告）
    桌面整理器.vbs  备用（脚本被拦 / exe 被杀软误杀时用，会问一次「无法验证发布者」）
    桌面整理器.bat  再备用（会开一个最小化的黑窗口，关掉即退出）
  它们找 Node 的顺序都是：
  本文件夹的 node\node.exe（便携版自带）→ 系统 PATH → Program Files。
  所以同一个文件夹，在装过 Node 和没装过 Node 的机器上都能直接跑。

  软件会以一个独立的窗口打开（不显示浏览器地址栏和标签页），
  关上窗口等于退出，后台进程会在空闲 60 分钟后自动结束。


【使用步骤】
  1. 打开软件后，先看「1 选择要整理的类别」。
     六类文件会自动统计数量：办公文档 / 图片 / 记事本 / 文件夹 / 压缩包 / 未知文件。
     想整理哪类就点哪张卡片（打勾＝选中），也可以右上角「全选」「清空」。
     点卡片上的「查看 N 个文件」可以先看清具体是哪些文件。

  2. 在「2 选择文件存放位置」里设定整理后的地方。
     - 点「浏览…」用系统对话框选文件夹（推荐）
     - 或者点下面的快捷标签（默认是 C:\Users\你的用户名\桌面归档）
     - 也可以直接在输入框里粘贴路径
     - 点「打开文件夹」可以直接在资源管理器里看这个位置（还没有会自动建）
     注意：存放位置不能选在桌面里面，否则整理完又回到桌面上了。

  3. 想保留一个入口，就勾选「整理完成后在桌面创建快捷方式」，
     右边可以改名字，默认叫「已整理的文件」。

  4. 点「开始整理」→ 会先弹出整理方案，把每个文件要去的位置列清楚，
     确认无误再点「开始整理」，文件才会真正移动。
     （点「先看看方案」是同样的预览，不会动文件）

  5. 整理完成后可以看到：成功 / 跳过 / 失败 各多少，
     还能「打开文件夹」去看结果，或者「撤销这次整理」全部还原。
     关掉结果窗口后，屏幕下方会留一条「刚整理了 N 个文件 · 撤销」的提示，
     不满意随时点「撤销」，文件会按原路回到桌面；点右边 ✕ 才会收起。
     桌面右上角「整理记录」里也能撤销以前任何一次整理。


【备份与恢复】
  撤销只撤得回最近一次操作；备份能把整个桌面搬回备份那一刻，更彻底。

  1. 从哪进去：窗口顶部有两个页签 ——「整理桌面」和「桌面备份」，
     点「桌面备份」就是备份页（一整页，不是小弹窗）。

  2. 第一次备份会先问「放在哪个文件夹」：
     · 点「浏览…」用系统对话框选，或者点下面的快捷标签，也可以直接粘路径。
     · 这个文件夹同时会成为「整理桌面」的默认存放位置
       （只是默认，整理那边还能单独改，两边可以不一样）。
     · 存档实际放在所选文件夹下面的「桌面备份」里，
       和整理出来的分类文件夹分开，不会混在一起。
     · 备份页和整理页都有「打开文件夹」，随时可以去资源管理器看一眼。
     第一次点「开始整理」「先看看方案」「打开重排面板」时，
     如果还没备份过，软件也会先提醒一次（只提醒一次）；
     提醒窗口里可以直接点「先备份（推荐）」，选好位置备份完再接着做刚才的事。

  3. 备份里有什么：
     · 桌面上所有文件、文件夹、快捷方式（用户桌面 + 公共桌面）原样复制一份，
       原文件不动、不删、不改名。
     · 每个图标的名字和坐标（icons.json），也就是"哪个图标在哪个格子"。
     · 只保留最近 5 份，更旧的会自动删掉。

  4. 以后每隔一段时间（比如装了新东西、存了新文件）打开软件，
     切到「桌面备份」点「立即备份」就行 —— 不用再选位置，路径记着了。
     只有新增和改动过的文件才真的复制，没变过的直接沿用上一份，
     所以第二次以后又快又不占空间。

  5. 怎么恢复：在「历史备份」里找到那一条 →
     · 「恢复」        ＝ 文件补回桌面 + 图标摆回那一次的坐标
     · 「只恢复图标」  ＝ 只改坐标，文件一个都不动
     · 「打开」        ＝ 在资源管理器里看这份备份
     · 「删除」        ＝ 删掉这份存档（桌面不受影响）
     恢复不会覆盖你现在的东西：桌面上已经有的同名文件会跳过。

  6. 回到"用这个软件之前"：
     每次重排都会记下"挪之前的坐标"，所以就算当时没备份，
     备份页最下面的「摆回最初的位置」也能把所有图标按第一次整理之前的样子摆回去
     （只改图标位置，文件不动）。

  7. 备份/恢复都有进度条。备份过程中别退出软件，
     中途退出会留下一份不完整的备份（它不显示在列表里，下次备份时会自动清掉）。


【分类与细分规则】
  办公文档 → 办公文档/Word 文档、Excel 表格、PPT 演示、PDF、其他文档
  图片     → 图片/2026-11（按文件修改月份分文件夹，照片多了也不乱）
  记事本   → 记事本/2026-11（TXT、MD、LOG、NFO 等，按月份分）
  文件夹   → 文件夹/（整个文件夹搬进去，不再细分，避免破坏里面结构）
  压缩包   → 压缩包/ZIP、RAR、7Z、ISO、GZ 等（按格式分）
  未知文件 → 未知文件/EXE、JSON、BAT…（按扩展名分，没有扩展名的单独一格）

  同名文件不会覆盖：会自动改名成「文件 (2).docx」这种形式。


【安全设计】
  · 桌面上的快捷方式（.lnk / .url）、系统图标（此电脑、回收站等）、
    隐藏文件、Office 临时文件（~$开头）一律不动。
  · 移动是「搬走」不是复制，桌面上的原件不会保留 —— 所以提供了撤销。
  · 整理过程中会显示实时进度条，正在搬哪个文件一目了然。
    现在不允许在整理途中退出软件；万一进程被强行结束，
    已经搬走的文件也逐个记在日志里（「整理记录」标为"未完成"），照样可以撤销。
  · 每次整理都会留一份记录，撤销时文件按原路返回桌面，
    并且会把这次在桌面创建的那个快捷方式一起删掉。
  · 跨磁盘（比如从 C: 搬到 D:）会自动改成先复制、校验成功后再删除原文件，
    不会出现只复制了一半就没了的情况。
  · 文件夹内有单个文件复制失败时，会清掉半成品、保留原文件夹，
    绝不删源，并在结果里报出是哪个文件、什么原因。
  · 整理完成后会自动通知 Windows 重绘桌面。因为「跨磁盘搬走」＝
    先复制到新盘、再删掉桌面原件，一次性删很多时资源管理器会漏掉通知，
    结果文件其实已经搬走了、桌面上却还留着图标，双击它只会提示
    「位置不可用 C:\Users\...\Desktop\xxx」。
    万一还是看到这种打不开的图标：在桌面空白处右键 →「刷新」（或按 F5）即可，
    也可以点软件里的「刷新桌面」按钮，效果一样。


【桌面快捷方式重排（实验性）】
  这一块和上面整理文件是两回事，互相不影响：
  整理文件＝把文件搬走；重排快捷方式＝只把图标在桌面上挪位置。

  1. 主界面最下面点「打开重排面板」，软件会读出桌面上所有快捷方式，
     按「日常软件 / 专业（小众）软件 / 游戏 / 桌面文件」自动分好四组。

  2. 右上角「图标 / 名字」可以随时切换显示方式：
     · 图标 —— 和桌面上一模一样的样子，一眼就能认出来
     · 名字 —— 紧凑的名字列表，一屏能看更多
     第一次打开会花一两秒读取图标，之后有缓存，再打开就很快。
     你选的那种会记住，下次打开还是它。

     图标视图下，右上角「图标大小」有 小 / 中 / 大 / 特大 四档，
     小＝一列能看 4 个，特大＝一列看 2 个但看得最清楚。
     也可以按住 Ctrl 滚滚轮直接缩放，不用去点按钮。
     这一档同样会记住。

  3. 这个面板是按窗口大小自己排版的：
     宽窗口四张卡片并排；窄一些（900 以下）折成两行两列；
     再窄就是一列到底。文字该换行就换行，不会出现被切掉半截的情况。
     软件启动时的窗口大小也是按你的屏幕算的（大约占屏幕 86%，
     居中显示，任务栏也扣掉了），1366×768 的笔记本和 2K、4K 屏都能装得下。

  4. 图标大小参差不齐的问题已经处理：
     有些程序的 .ico 图案其实只占画布中间一小块（四周是空白或淡阴影），
     照原样缩放就会显得特别小。软件在读取图标时会自动裁掉这些空白，
     让每个图标都按实际图案大小显示，所以看起来大小更统一。
     （只改缓存的图片，不动快捷方式本身；识别不出来时按原样显示，不会裁坏。）

  5. 觉得哪个分错了：直接把它拖到另一个框里。
     拖动时四个框都会亮起虚线，目标位置有蓝色竖线提示，松手就落在那里；
     在同一个框里上下拖，可以调整组内顺序。
     拖过去以后软件会记住（data\shortcut-map.json），
     以后同一个程序永远按你拖的走，不会再问。

  6. 每组上方有两个开关：
     · 「参与整理」勾选框 —— 不勾这一组就原地不动，完全不管它
     · 「左 / 右」         —— 这一组靠在桌面左边还是右边

  7. 四组之间的先后顺序：直接按住那张卡片拖 —— 抓标题条、抓卡片空白处都行，
     真图标和勾选框上的点击不会被误当成拖动。
     窗口够宽（差不多 1100 以上）时标题右边还有 ↑ ↓ 小箭头，点着也能调。
     拖动时被抓的那张会变淡，落点上会出现一条竖色带。
     规则一句话：面板里从左到右，就是桌面上从左到右。
     所以 ① 永远在最左边，④ 永远在最右边（同一侧之内）。
     例：① 日常（左）② 专业（右）③ 游戏（右）
         结果＝左边是日常，右边靠外的是游戏、游戏左边是专业。
     想让游戏贴最右边，就把游戏拖到最后一个（④）。
     窗口拉得很窄（笔记本小屏、分辨率低）时，四张卡片会折成两行两列，
     卡片左上角的 ①②③④ 就是顺序，照样能拖。
     靠边的那一组会紧贴桌面边缘：图标格子的最后一列只要还放得下图标本身，
     就会用上它，所以左边、右边留白基本一样，不会出现"最右边空一条"。

  8. 效果图右上角「组与组之间」：
     · 另起一列   —— 一组排完如果这列还有空位，下一组另起一列（留空）
     · 不留空接着排 —— 直接接着空位往下排，中间不留缝
     换一下，下面那张桌面效果图会立刻重画，不用点任何按钮。

  9. 第四个框「桌面文件」（不是快捷方式，是文件本身）：
     里面有六类 —— 办公文档 / 图片 / 记事本 / 文件夹 / 压缩包 / 未知文件，
     每一类都是一个带图案的小图标，图标右上角的小圆点是这一类现在有几个。
     · 这六个图标只能左右拖，拖到哪个图标的左半边就插到它前面；
       它排第几，桌面上就是第几块。卡片太窄时它们会自动折成两行三个，
       名字和图标都不会被挤掉。
     · 重排时同类会先聚成一块，再按你排的顺序一块一块摆开，
       不会出现"图片夹在两堆文档中间"。
     · 想让每一类各占一列就用底部「另起一列」；
       想省地方就用「不留空接着排」。
     · 框底「建分类文件夹并归档」：勾上以后，软件会在桌面上建六个文件夹
       （名字就是这六类），把对应类型的文件真的移进去。这是整个重排里
       唯一会动文件的地方，所以点「确认重排」时会再问一次你。

  10. 面板最下面那张「桌面效果」图是实时的，不用点按钮：
     灰点是图标现在的位置，彩点是重排后的位置，改一下就重画。
     · 拖图标换分类、拖列标题调组顺序、切换左/右、换排法、勾归档 ——
       每动一下，图上的点和右边的数字都会跟着变（几十毫秒，肉眼基本无感）。
     · 右边那几行是这一趟的结果：哪一组排哪侧、几个图标、占几列；
       位置不够、会归档多少文件也会写在这里。
     · 图里每个点的大小是照着你桌面上的格子来的 —— 系统设置里把图标调大调小、
       换了分辨率，图上的点会跟着变，不会糊成一片，也不会散成芝麻。
     · 觉得图占地方，点左上角的 ▾ 可以把它收起来，收起来的状态会记住
       （屏幕很矮的机器第一次打开时它默认是收起的，点一下就能展开）。
     · 窗口窄的时候，右边那几行说明会自动挪到图的下面，不会左右被挤掉。
     看着满意就点「确认重排」，不满意接着拖就行。

     注意：桌面上的快捷方式其实来自两个地方 ——
     你自己的桌面，和「公共桌面」（C://Users//Public//Desktop，
     装软件时选「所有用户」的快捷方式会放这里）。两个位置都会一起整理，
     不会出现"整理完中间还剩一堆图标"的情况。
     桌面上的文件、文件夹现在也会参与重排（就是第四组「桌面文件」）；
     只有此电脑、回收站这类系统图标不会被挪。

  11. 排完如果不满意，有三条路可以撤回：
     · 结果窗口里的「还原到原来的位置」
     · 关掉窗口后屏幕下方的撤销提示条
     · 「整理记录」→ 图标重排 →「还原」
     每个图标都会按记录下来的坐标原样放回去。


【这一块的安全边界】（重要）
  · 默认只做一件事：改图标的坐标。不创建、不删除、不移动、不改名任何文件。
    代码里走的是 Windows 桌面的「设置图标位置」消息，没有删除相关的调用。
  · 唯一例外是「建分类文件夹并归档」：只有你手动勾上、又在确认窗口点过
    「确认移动」，才会真的把文件移进桌面上的六个分类文件夹。
    这次移动会写进「整理记录」，结果窗口和下方提示条都能一键撤回；
    重名的文件会自动加序号，绝不覆盖。
  · 那六个分类文件夹本身不会被再归档一次（否则会自己套自己），
    它们只会跟着其它图标一起排位置。
  · 不参与重排的：此电脑、回收站这类系统图标；没勾「参与整理」的分组。
    它们会被当成"障碍物"绕开，不会被压在上面。
  · 执行前需要桌面处于「自动排列图标」关闭状态：
    桌面右键 → 查看 → 取消勾选「自动排列图标」（「对齐到网格」可以留着）。
    如果它是开着的，软件会提示你先关掉，不会硬来。
  · 每次重排都会存一份坐标记录（data\icon-logs\），可以原样还原。
  · 桌面图标一次要写上百个位置，软件会按 Windows 命令行长度自动分批发送，
    写完还会读回来核对一遍，被系统挤开的会补正一次。
  · 图标是从系统里读出来的图片（只读），缓存在 data\icon-cache\，
    快捷方式文件本身不会被改动；换图标后缓存会按修改时间自动更新。
  · 万一你重排后自己又手动挪过某些图标，还原时那些图标会被跳过，不会硬拽回去。

【清理桌面】
  顶部第三个页签，专门收拾桌面上已经打不开的图标。

  1. 先看备份 —— 所有清理动作开始前都会检查：
     · 备份过：页面上是绿色的一条「已经备份过桌面」，直接可以清理。
     · 没备份：页面上是橙色的一条「还没有备份过桌面」，
       要么点「去备份（推荐）」先存一份（十几秒，备份完会自动回到这一页），
       要么自己勾上「我知道未备份就清理桌面图标的风险，仍然继续」。
       勾上之后本次可以直接清理；关掉软件再打开要重新勾一次。
       扫描结果弹窗底部也有同一个勾选框，和页面上是同一个开关。

  2. 「失效图标」→ 点「开始扫描」。
     软件会检查桌面上每个 .lnk / .url 还指不指得到东西：
     · 指向的程序 / 文件夹被删掉、卸载、改名了 → 判为「确定失效」
     · 指向的是 U 盘 / 移动硬盘，现在盘没插 → 判为「可能是磁盘没连上」，默认不勾
     · 网络位置、应用商店应用、路径里带认不出的环境变量 → 不判断，直接跳过
     扫描是只读的，不改动任何文件，通常一两秒。

  3. 弹窗会列出所有失效图标，默认全勾选；想留哪个把勾去掉就行。
     右上角有「全选 / 全不选」，列表里也能一个一个点。
     每行都写着它原来指向哪里、为什么判为失效。

  4. 点「清理选中的 N 个」之后：
     · 快捷方式进回收站（不是永久删除，回收站里还能找回来）
     · 本机再留一份原件（data\cleanup\），在「最近清理」里点「放回桌面」随时还原
     · 只删快捷方式本身，桌面上的文件和文件夹一个都不碰
     · 删完自动刷新桌面，失效图标立刻消失

  5. 「最近清理」列出每次清理的时间、清了几个、都是谁，可以一键放回桌面。

  6. 「按软件卸载」—— 桌面图标按类型排成四列，可以一次勾多个软件，
     它会一个一个弹出这些软件自己的卸载向导。

     ① 点「打开卸载面板」，软件会读一遍注册表里的软件清单（约两三秒），
        然后把桌面上认得出软件的图标按四类摊开：
        · 日常软件 / 专业（小众）软件 / 游戏 / 认不出·卸不了
        点图标就是勾上，再点一下取消；每列标题右边有「全选」，
        上面还有「全选能卸的 / 清空」，也能用搜索框按名字找。
        同一个软件在桌面上有两个图标（比如「抖音」和「抖音 (2)」），勾一个就都算上。
        认不出的那一列是绿色软件、商店应用、失效图标、文件夹入口 —— 它们没有卸载程序，
        标着原因，不参与批量卸载。

     ② 点「下一步：确认清单」，会列一张表：软件、怎么卸（系统安装包 MSI 还是它自己的卸载程序）、
        安装位置、还剩多少处残留。这时候还没动任何东西，行尾的 ✕ 可以把它从清单里去掉。

        如果还没备份过桌面，这一步会拦一下：要么点「先备份」，
        要么勾上「我知道没备份的风险，仍然继续」。

     ③ 点「开始卸载」→ 按清单顺序一个一个弹出软件自己的卸载向导，
        按提示点完就行（我们不会替你静默卸载 —— 各家静默参数不一样，猜错了更麻烦）。
        哪个跑完都会自动检查结果，然后进下一个，不用你点。

     ④ 怎么算成功、怎么算取消：
        · 成功 —— 软件从系统里消失：注册表里的卸载登记项没了，或者安装目录被清空
        · 取消 —— 卸载向导关掉了，但软件还在（登记项还在、目录没动、也没有进程在跑）
        两种都算跑完，都会自动进下一个；真卡住了最多等 6 分钟也会跳过。
        点「停止卸载」只影响后面的软件，正在弹的那个不会被强杀（卸一半强杀更糟）。
        中途把整个面板关掉，也等于停止，后面的不会再弹出来。

     ⑤ 全部跑完进结果页：成功几个、取消几个、跳过几个，一个个列出来。
        成功的那几个，卸载程序没清干净的东西（桌面图标、剩下的安装目录、缓存）会分组列出，
        勾上点「清理选中的 N 项」，**要再点一次确认**（6 秒不点自动取消），
        然后一起丢进回收站 —— 删错了能还原。
        另外还有一块「注册表项」是**只展示、不动手**的：注册表删了没有回收站，
        误删会影响右键菜单、文件关联、服务，而且删了也就省几 KB，不值当。
        想知道在哪，点「定位」会打开注册表编辑器跳到那个位置，自己看。

     这一步的安全边界：
     · 只清「这次卸载任务自己算出来的路径」，前端传别的路径后台一律拒绝。
     · 系统目录、盘符根、用户目录根、AppData 根、Program Files 本身、
       ProgramData\Package Cache（删了这软件以后想修复都修不了）—— 全部黑名单。
     · 文档（Documents）里跟软件同名的目录**永不勾选**，只在确认页提示一句，
       因为游戏存档就爱放那儿，删了找不回来。
     · 注册表只读，任何情况下不写、不删。

  【这一块的安全边界】
  · 只处理桌面根目录下的 .lnk / .url，不递归进任何文件夹。
  · 只清理「刚刚扫描出来、并且确实判为失效」的那些：
    别的路径（比如 C://Windows//notepad.exe）传到后台会被直接拒绝。
  · 删除走回收站，不调用永久删除；每批清理前都会先把 .lnk 原件复制一份留底，
    留底最多 12 份，超出自动删最旧的。
  · 没有备份又没有勾风险确认时，后台也会拦住（不只是按钮变灰）。

  7. 「所有已安装的软件」—— 桌面没有图标的软件，在这里也能卸。
     读的是注册表里完整的软件清单（包括 Windows 默认藏起来的那一批），
     按用途分成六类：

     · 日常软件   —— 浏览器、聊天、网盘、办公、播放器、输入法。42 个里有你桌面上没有的。
     · 专业 / 开发 —— Adobe、CAD、剪辑、虚拟机、各种 IDE 和 SDK。
     · 游戏       —— 从 Steam / 战网 / EA / Ubisoft 装的游戏，和平台客户端本身。
     · 驱动 / 硬件 —— 显卡、声卡、网卡、手柄驱动。**这一类要先勾确认才能选**。
     · 系统组件 · 运行库 —— C++ 运行库、.NET、Python 组件、编解码器包。
                     **这一类也要先勾确认**，而且卸错了会让别的软件打不开。
     · 认不出     —— 注册表里信息太少，只能靠名字猜。

     分类是怎么判的（不是瞎猜，每条都能说清理由）：
     · 装在 steamapps 目录里、或者卸载命令是 steam://uninstall/12345 的 → 游戏
       这招最准，连「LocalThunk」这种看不出是什么的发行商也认得出是游戏。
     · 注册表里标着 SystemComponent=1 的 → 系统组件（这些默认连控制面板都不显示）
     · 名字里有 Redistributable / Runtime / .NET / DirectX → 运行库
     · 名字里有 Driver / 适配器 / 蓝牙 → 驱动
     · 发行商是 Adobe / Autodesk / Maxon / JetBrains → 专业软件
     · 名字里有网盘 / 浏览器 / 输入法 / 音乐 → 日常软件

     每行右边的分类标签（蓝色小方块）**可以点开改**：
     判错了直接选个对的，改完记在本地，下次打开还是你选的那个。

     同一个软件在注册表里常常躺好几条（64 位一条、32 位一条、用户级一条），
     这里已经合并成一行，副标题会写「注册表里 N 条」。
     卸的时候按主条目走，剩下的空壳会在结果页列出来。

     没写占用体积的（Steam 游戏基本都不写），会显示「统计中」然后按安装目录现算，
     算出来的是真实占用。装目录已经不在的显示「—」—— 那说明注册表项是残留。

     勾选 → 下一步 → 后面的流程和「按软件卸载」完全一样：
     一个接一个弹出它们自己的卸载向导，取消算失败、没弹出来算成功，都自动进下一个。

  【这一块的安全边界】
  · 系统组件 / 运行库 / 驱动这三类默认**勾不了**，
    要先勾「我知道这类东西卸错了会让别的软件或硬件不好用」才放开。
    这不是多此一举：卸掉 VC++ 运行库，一堆软件会直接报「缺少 dll」打不开。
  · 卸载永远走软件自己的卸载程序，不会自己去删目录、不会碰注册表。
  · 收尾清理时只清这次任务自己算出来的路径，别的路径后台一律拒绝。

【软件是怎么认出来的】（重要）
  所有判断都是打开软件那一刻，从你电脑上现读的，没有任何"提前写好的名单"：
  · 桌面上有什么图标 —— 读桌面文件夹，快捷方式的目标 / 参数 / 公司名用系统接口解出来
  · 图标长什么样 —— 用系统接口从那个 .exe / .lnk 上现抠 256px 图，不联网、不猜
  · 装了什么软件 —— 读注册表里的三处卸载项（64 位 / 32 位 / 当前用户）
  · 属于哪一类 —— 按公开的通用规律判：装在 Steam 库目录、卸载命令走 steam://、
    发行商是游戏公司、名字里有 Photoshop 这种产品名……每条判断都会写清理由
  · 唯一的"个人数据"是你自己点过的分类：你改一次它就记住（存 data\shortcut-map.json）。
    这部分是你教的，不是软件猜的，也不是预先写死的。

  所以换一台电脑、换一个桌面，这套规则照样成立。判不出来的会老实显示「认不出」，
  不会硬塞一个分类 —— 目前这套规则在这台机器上判不出的只有 2 个。


【窗口大小和缩放】
  · 窗口窄到 760 以下，顶栏自动分成两行（页签单独一行），按钮不会被挤出去
  · 内容区宽度跟着窗口走：1040 → 1260 → 1460 → 1660，2K / 4K 屏上不会被挤成中间一条
  · 系统缩放 125% / 150% / 200% 都按同样逻辑走（浏览器给的是逻辑像素，缩放会自动换算）
  · 快捷方式面板的「图标大小」四档（小 / 中 / 大 / 特大），格子高度会跟着档位变，
    调到特大也不会只看到两行；Ctrl + 滚轮同样能调
  · 卸载 / 重排这些面板在窄窗口里撑满可用宽度，不会把右边的关闭按钮顶出屏幕


【能在哪个 Windows 上用】
  · 开发与实测环境是 Windows 10 22H2；Win11 用的是同一套系统接口，可以直接跑。
  · 用到的都是 Win10 1607 起就有、Win11 一路保留的东西：
    注册表卸载项、.lnk 解析、桌面图标视图（Progman → SHELLDLL_DefView → SysListView32）、
    SHChangeNotify、回收站删除（Microsoft.VisualBasic.FileIO）、PowerShell 5.1。
  · 需要：Windows 10 1607 及以上 / Windows 11 任意版本（21H2 ~ 25H2），64 位；
    PowerShell 5.1 与 .NET Framework 4.x（系统自带，不用另外装）；
    Node.js 18 以上（便携版已经把 Node 22 装在 node\ 里，不用自己装）。
  · 不需要管理员权限。只有个别卸载程序自己要提权时，才会弹「用户账户控制」。
  · 系统缩放 125% / 150% / 200% 已适配：桌面图标网格按物理像素测量，
    不会出现「右边空一条、图标却说放不下」。
  · ARM64 机器（骁龙本）：能跑，但默认用的是 x64 版 Node，靠系统模拟，启动会慢一点；
    换成 ARM64 版 Node 会明显快。
  · 不支持的：Windows 7 / 8（缺 PowerShell 5.1 和回收站接口）、
    Windows 11 S 模式（只能装商店应用，跑不了外部程序）。
  · 已知没实测的：多显示器组合（这台机器是单屏）。副屏上如果有图标，
    整理前先拖回主屏更稳妥。


【分享给别人】
  打包：node tools\pack.js --all
    会在 dist\ 里生成两个包，按对方情况挑一个发（只想出一个就加 --portable 或不加参数）。

  1) dist\桌面整理器-便携版.zip（约 32 MB）—— 一般就发这个
     Node 运行时已经打进 node\ 里，对方不用装任何东西：
     解压到有写权限的文件夹（例如 D:\桌面整理器，别放 C:\Program Files，
     那里写文件要管理员权限）→ 双击「桌面整理器.exe」→ 就能用了。
     不需要安装，也没有安装程序；想从桌面图标进再双击「放到桌面（可选）.vbs」。
     没签名的 exe 第一次运行会被 SmartScreen 拦一下（「Windows 已保护你的电脑」），
     点「更多信息 → 仍要运行」即可，只这一下；让对方解压前先右键 zip → 属性 →
     勾「解除锁定」，这一下也不会出现。
     杀毒软件如果报 node.exe，那是 Node.js 官方运行时原样打包（node\LICENSE.txt
     是它的授权文件），不是病毒；介意就改用标准版。

  2) dist\桌面整理器.zip（约 240 KB）—— 对方已经装了 Node 18+ 时用
     只有程序本身，解压后先看「第一次使用请读我.txt」，装 Node 再双击「桌面整理器.exe」。
     体积小，适合通过限制附件大小的邮箱或聊天工具传。

  · 两个包都带三个入口：桌面整理器.exe（首选，正常程序）、桌面整理器.vbs（脚本备用）、
    桌面整理器.bat（最兜底）。对方只认 exe 也没问题，另外两个留着不占地方（各 2 KB）。
  · 对方第一次打开可能弹「Windows 已保护你的电脑」或「无法验证发布者」。
    这不是杀毒报警，是「没签名 + 从网上下载」共同造成的。
    解压前先做一次：右键 zip → 属性 → 勾选「解除锁定」→ 确定，再解压，
    之后双击就没有任何提示了。用微信 / QQ 传的包更容易带这个标记。
  · dist\SHA256SUMS.txt 是这批发包的 SHA-256 值。对方想确认没被改动，
    在 PowerShell 里跑 Get-FileHash 对一下即可 —— 没买数字签名时，
    这是唯一免费、又真能起作用的完整性凭证。
  · 两个包都不含 data\：里面是你的配置（比如归档到哪个文件夹）、整理记录、
    清理记录和图标缓存，属于个人数据，对方也用不上。
  · 这个包没有安装程序、没有依赖、不写注册表，删掉文件夹就等于卸载干净。
  · 便携版文件夹挪到别处后，桌面快捷方式会失效（lnk 里存的是绝对路径），
    重新双击一次「放到桌面（可选）.vbs」就好。
  · 重新出包前如果改了启动器（tools\launcher\Program.cs），要先重编译：
        node tools\make-launcher.js
    再 node tools\pack.js --all。只改界面 / 功能代码不用重编译 exe ——
    它只负责找 Node 并拉起 server.js。


【出问题时】
  · 点「浏览…」没反应：直接在输入框里粘贴路径，效果一样。
  · 提示"创建快捷方式失败"：整理本身已经成功，可以直接用「打开文件夹」进去，
    手动右键该文件夹 →「发送到」→「桌面快捷方式」。
  · 桌面上有打不开的图标（提示「位置不可用」）：那只是图标没刷新，
    文件已经安全搬家了。桌面右键 →「刷新」，或点软件里的「刷新桌面」。
  · 整理记录存在 data\logs\ 目录下，纯文本 JSON，可随时查看。
  · 清理完图标还在：那说明那个快捷方式没删掉（多半被别的程序占用），
    「最近清理」里会留有记录；关掉占用的程序再扫一次即可。
  · 清理错了想恢复：清理桌面 → 最近清理 → 找到那一条 → 「放回桌面」，
    图标会回到原来的位置（桌面上的同名项目已存在时会跳过，不覆盖）。
  · 卸载点了没反应 / 只闪一下：多半是它要管理员权限被拦了。软件会自动再试一次，
    这时屏幕会弹「用户账户控制」，点「是」就行。
  · 批量卸载卡在某一个很久：某些软件的卸载程序会先复制到临时目录再跑，慢是正常的。
    最多等 6 分钟就会跳过它继续下一个；也可以点「停止卸载」把后面的停掉。
  · 结果页显示「取消」：说明那个卸载向导被关掉了（或者在里面点了取消），软件还在。
    重新勾它再卸一次就行，或者去「设置 → 应用」里卸载。
  · 关掉卸载面板后还有窗口弹出来：不会了 —— 关面板时就等于按了停止，
    只有当时已经弹出来的那个窗口还在。
  · 残留清理清错了：都在回收站里，打开回收站还原对应的那个文件夹即可。
  · 「所有已安装的软件」里找不到某个软件：它可能是绿色软件（没走安装程序，注册表里没登记），
    或者是商店应用（设置 → 应用里卸）。这两种都不会出现在这里。
  · 分类判错了：点那一行右边的分类标签直接改，改完会记住。
  · 双击 .vbs 没反应（有些机器禁用了 Windows Script Host，或被杀软拦了）：
    改用「桌面整理器.exe」或「桌面整理器.bat」。
  · 双击 exe 没反应 / 提示「不是有效的 Win32 应用程序」：
    说明文件在下载或解压时坏了，重新解压一次包；也可以先用「桌面整理器.vbs」顶着。
  · 提示「没找到 Node.js 运行时」：便携版的 node\node.exe 应该就在旁边，
    确认整个文件夹是一起解压出来的（别只把 exe 拖出来用），或者装一个 Node 18+。
  · 提示找不到 Node：双击「桌面整理器.bat」会在窗口里显示它找过哪些位置；
    装一个 Node.js 18+ 后重开即可（便携版自带 node\，不会有这个问题）。
  · 桌面图标整理完位移不对、右边空一条：检查系统缩放是不是 125% / 150%，
    以及显示器是不是多屏拼接 —— 单屏 + 单缩放是最稳的组合。
    想全部重判，把 data\config.json 里的分类记忆删掉即可（或者清一下浏览器本地存储）。
  · 软件名字是乱码：注册表里存的就是坏编码（有些盗版/绿色安装包会这样），
    软件会把后面的乱码截掉，但前面那截认不回来。不影响卸载。
  · 体积显示「—」：注册表里没写占用，而且安装目录已经不在了 —— 说明这是个残留条目，
    可以放心卸掉（或者直接勾上一起去掉）。
  · 想恢复默认设置：删掉 data\config.json 再打开软件。
